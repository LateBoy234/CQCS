- `ColorQualityControl` 是 WPF 表现层（.NET Framework），`ThreeNH.SQCX.*` 是迁移中的 Clean Architecture 三层（Application / Domain / Infrastructure / McpServer）。
- 11 个仪器适配器已合并到 `ThreeNH.SQCX.Infrastructure/Instruments/`：PTS、ColorReader、LedSpectrometer (含 GratingSpectrometer)、CR400、BTS / NRColorimeter / YRColorimeter (Bluetooth)、YL30 + ThreeNH.YL30、Spectrophotometer (Common)。

- MCP 只暴露 4 个只读工具：`sqcx_get_application_context`、`sqcx_list_standards`、`sqcx_list_tests`、`sqcx_get_test_details`。

## `get_application_context` 响应结构（WPF 端定义）

来源：`ColorQualityControl/Agent/Mcp/SqcxAgentQueryService.cs::GetApplicationContext`，
所有访问派发到 UI 线程，调用 `MainWindow` 上的 `Database / Colorimeter / CurrentStandard / CurrentTest / SpecularComponent / Illuminant / Observer / Session.Instrument.ConnectionState / InstrumentType / DeviceSN`。

```json
{
  "application": { "name": "App.Title", "version": "App.AppVersion" },
  "job": {
    "fileName": "<database.FilePath 的文件名，null 表示无文件>",
    "isModified": "<database.IsModified>",
    "lastModifiedAt": "<database.LatestModificationTimestamp>",
    "standardCount": "<database.StandardSpecimens.Length>",
    "testCount": "<database.TestSpecimens.Length>",
    "orphanTestCount": "<database.OrphanTests.Length>"
  },
  "measurementContext": {
    "specularComponent": "<SCI|SCE>",
    "illuminant": "<D65|D50|…>",
    "observer": "<2°|10°>"
  },
  "selection": {
    "currentStandard": "{id,name} | null",
    "currentTest": "{id,name,standardId} | null"
  },
  "instrument": {
    "connected": "<instrument != null && instrument.IsOpen>",
    "connectionState": "<window.Session.Instrument.ConnectionState>",
    "type": "<window.InstrumentType>",
    "model": "<instrument?.Model>",
    "deviceName": "<instrument?.DeviceName>",
    "serialNumber": "<RedactSerialNumber: 前缀遮蔽、保留末 4 位>"
  },
  "safety": { "access": "read-only", "note": "MCP 不能 connect / calibrate / measure / modify / save / delete" }
}
```
